# 前端观察室 · Frontend Learning

面向不想手写代码、希望看懂 UI 并与 Coding Agent 协作的中文交互课程。

当前已完成第一节「页面不是一张图」、第二节「Flex——一维排列」、第三节「Grid——二维布局」、第四节「Position与浮层」、第五节「Sizing与Overflow」、第六节「响应式设计」、第七节「圆角、阴影与层级」和第八节「毛玻璃」。其余章节只提供目录与“尚未制作”提示，第九节尚未制作。路线核对日期为 **2026-10-20**，官方参考链接可在网站底部展开。

## 第一节

约 18 分钟，五站交互：

1. 原创「留白」聊天界面与组件树双向点选；切换由示例实际节点生成的 DOM 元素树。
2. 增加 Message 实例，共同调整圆角，观察复用。
3. 修改第二条消息的 role、status、content，实时观察参数驱动 UI。
4. 三道可重试判断题，逐题提供理由。
5. 生成、编辑与复制 Agent 指令；复制被拒绝时选中全文并提供手动复制说明。

教学聊天界面不会发送消息，不代表任何真实产品的内部实现。指令生成器使用本地规则，不调用 AI 批改。进度、参数和草稿只存于当前浏览器的 localStorage；无跨设备同步，提供重置对话框。

## 第二节：Flex——一维排列

按课程顺序学习一维排列，约 18 分钟，五站交互：

1. 真实 Flex 容器切换 row / column 与 gap，显示主轴和交叉轴；观察按钮组与图标、标题、描述、按钮卡片。
2. 在头像、用户名和右侧设置示例中对比 justify-content / align-items，切换方向验证两条轴的变化。
3. 调节容器宽度和中间项目的 grow / shrink，显示浏览器实测外框宽度；故意制造长内容的最小尺寸限制，再允许项目收缩与换行。
4. 三道可重试判断题，说明方向、基础尺寸和最小尺寸约束。
5. 生成可编辑的 Agent 指令，包含方向、间距、对齐、尺寸约束、长内容、键盘操作与手机验收。

Figma Auto Layout 仅作设计意图的近似映射，不与 CSS 值机械等同。Grid 留在第三节，不在第二节提前实现。第二节独立使用 `frontend-observatory.lesson2.v1` 存储进度，重置第二节不会清除第一节已有进度。

## 第三节：Grid——二维布局

约 18 分钟，五站交互：

1. 改变列数、row-gap / column-gap、第一张卡片的 grid-row / grid-column 跨轨道规则，观察真实行列。
2. 对比 1fr + 1fr、1fr + 2fr、固定侧栏 + 弹性主区；读取实际轨道宽度，理解 fr 分配的是扣除固定轨道和间隙等后的可分配空间。
3. 比较固定三列与 repeat / minmax / auto-fit 自适应卡片；调节容器、首选最小宽度、卡片数和长内容。
4. 三道 Flex / Grid 判断题，重试并阅读理由。
5. 生成、编辑与复制 Grid Agent 指令，包含轨道约束、窄容器、异常内容、键盘和兼容性验收。

第三节使用独立键 `frontend-observatory.lesson3.v1`，重置仅清除本课数据。前两课的存储格式和键保持不变。核心排布由 CSS 完成，JavaScript 只读取浏览器测量结果。第三节技术参考核对日期为 **2026-10-21**。

## 第四节：Position 与浮层

约 18 分钟，五站交互：

1. 在正常流、relative、absolute 间切换卡片角标；改变偏移和定位参照，读取正文与角标的真实位置。
2. 在独立 iframe 内比较 static、sticky、fixed，滚动到 0 / 220 / 680px 并核对所属区段边界。演示中的 fixed 不遮挡课程页面。
3. 实际叠放父子层叠上下文，先提高子元素再提高父上下文；对比有边缘避让的非模态锚点浮层与原生模态 dialog，用关闭按钮或 Esc 退出并验证焦点返回，纯触屏也能完成。
4. 定位与浮层判断题，错误反馈和重试。
5. 角标、吸顶栏、模态对话框三类可编辑 Agent 指令。

第四节使用独立键 `frontend-observatory.lesson4.v1`，重置不会清除前三节。dialog 使用 showModal()；明确初始焦点、Tab / Shift+Tab 的可见焦点循环、Esc / 关闭按钮和焦点返回。不支持或打开失败时给真实提示，并可使用同一入口重试。非模态锚点实验优先使用原生 Popover，能力不可用或打开异常时回退到 Portal + fixed；以 JS 测量实现上下避让和横向回推，滚动时更新或收起。外点关闭保留其他控件的后续操作，点空白或关闭按钮则返回锚点焦点。Portal 不保证免于所有层叠与遮挡，区别于浏览器顶层。技术参考核对日期为 **2026-10-21**。

## 第五节：Sizing 与 Overflow

约 18 分钟，五站交互：

1. 改变父容器、width、min-width、max-width、padding 和 box-sizing，读取可用宽度与边框盒实际尺寸。
2. 用超长标题比较自动最小宽度、min-width: 0、溢出可见、局部滚动、clip、ellipsis 与换行；所有模式都有触屏和键盘可操作的全文入口。
3. 增加消息，在 350px 独立实验页中比较整页与消息区内部滚动；解除中间 Flex 项的最小高度约束，访问最后一条消息。两种结构按产品约束选择。
4. 三道可重试尺寸、盒模型与内容可达性判断题。
5. 生成可编辑的尺寸 / 溢出 Agent 指令，明确滚动归属、截断边界、全文入口、长内容与窄容器验收。

第五节以 `frontend-observatory.lesson5.v1` 独立保存浏览器进度，重置保留前四课。故障与故意裁切仅在清晰标注的实验区出现，保护边界可滚动；省略与裁切内容保留完整访问途径。不以隐藏重要内容作为修复。技术参考核对日期为 **2026-10-21**。

## 第六节：响应式设计

约 18 分钟，五站交互：

1. 独立调整 iframe 示例视口、media query 断点和课程内组件容器宽度；原生媒体查询与尺寸容器查询分别响应。
2. 同一个导航节点在桌面侧栏与窄屏模态抽屉之间切换，实际卡片横纵重排；验证关闭、Esc、返回焦点和打开时跨断点清理。iframe 的模态范围仅限实验页。
3. 内容压力与操作优先级：长标题完整换行、主要操作保留，次要操作经可访问的更多入口到达。触摸目标留出空间，不依赖 hover。
4. 三道可重试的查询策略、断点与抽屉判断题。
5. 可编辑、可复制的响应式 Agent 指令，覆盖布局变化、容器策略、内容优先级、触摸、键盘与兼容回退。

独立进度键 `frontend-observatory.lesson6.v1`，重置保留前五课。容器查询能力检查失败时保留可读单列与自然换行操作；示例断点按各自内容约束选择，不把 768px 当作普适答案。官方参考核对日期为 **2026-10-21**。

## 第七节：圆角、阴影与层级

约 18 分钟，五站交互：

1. 在同一张可操作卡片上调节圆角、边框、阴影和表面亮度，并与固定参考对照；状态有文字、符号和语义，焦点不依赖阴影。
2. 对同一份原创透明 SVG 同时应用 box-shadow 与 drop-shadow，切换镂空轮廓、模糊、偏移、扩散与不透明背景，比较作用对象。
3. 在局部画布中改变视觉阴影与真正 z-index，用原生命中测试测量交叠点；不把视觉 elevation 当作排序或真正浮层。
4. 三道可重试判断题及理由。
5. 可编辑、可复制的 Agent 指令，包含表面层次、边界、可读性、状态、焦点、绘制成本与兼容性。

独立进度键 `frontend-observatory.lesson7.v1`，重置保留前六课。图形交叠是明确标记的只读实验，操作留在画布外；表面效果不靠替换截图。不把夸张阴影作为“高级感”标准。官方参考核对日期为 **2026-10-21**。

## 第八节：毛玻璃

同一原创场景切换无滤镜、`filter: blur()` 与 `backdrop-filter`，观察自身内容和背景的真实区别。背景色 alpha、盖实面板、移除图案与手动位置操作改变实际结果；不额外生成假磨砂纹理。背景缓慢移动可暂停，响应系统减少动态偏好，所有门槛都有静态触屏和键盘路径。

第三站调整真实作用范围与半径，并模拟不支持时的不透明回退；文字使用稳定底色、边界和文字状态。解释 backdrop root、兼容性、可读性及目标设备性能预算，不虚构跑分。包含三道带理由的重试题、两种可编辑简报、复制失败回退和独立浏览器进度。独立进度键 `frontend-observatory.lesson8.v1`，重置保留前七课。官方资料核对日期为 **2026-10-21**。

## 本地开发与静态构建

需要 Node.js 22.12+（或 Vite 支持的版本）。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`dist/` 是可部署到静态托管服务的产物，无后端和运行时密钥。Sites 的持久项目标识保存在 `.openai/hosting.json`，后续发布应复用该标识，不能重复注册。GitHub 代码公开与 Sites 访问权限独立；本站 Sites 使用仅本人访问的权限。
