# 前端观察室 · Frontend Learning

面向不想手写代码、希望看懂 UI 并与 Coding Agent 协作的中文交互课程。

当前已完成第一节「页面不是一张图」和第二节「Flex——一维排列」，第三节 Grid 及后续课程只提供目录与“尚未制作”提示。路线核对日期为 **2026-10-20**，官方参考链接可在网站底部展开。

## 第一节

约 18 分钟，五站交互：

1. 原创「留白」聊天界面与组件树双向点选；切换由示例实际节点生成的 DOM 元素树。
2. 增加 Message 实例，共同调整圆角，观察复用。
3. 修改第二条消息的 role、status、content，实时观察参数驱动 UI。
4. 三道可重试判断题，逐题提供理由。
5. 生成、编辑与复制 Agent 指令；复制被拒绝时选中全文并提供手动复制说明。

教学聊天界面不会发送消息，不代表任何真实产品的内部实现。指令生成器使用本地规则，不调用 AI 批改。进度、参数和草稿只存于当前浏览器的 localStorage；无跨设备同步，提供重置对话框。

## 第二节：Flex——一维排列

按课程顺序学习一维排列，约 18 分钟，五站交互：

1. 真实 Flex 容器切换 row / column 与 gap，显示主轴和交叉轴；观察按钮组与图标、标题、描述、按钮卡片。
2. 在头像、用户名和右侧设置示例中对比 justify-content / align-items，切换方向验证两条轴的变化。
3. 调节容器宽度和中间项目的 grow / shrink，显示浏览器实测外框宽度；故意制造长内容的最小尺寸限制，再允许项目收缩与换行。
4. 三道可重试判断题，说明方向、基础尺寸和最小尺寸约束。
5. 生成可编辑的 Agent 指令，包含方向、间距、对齐、尺寸约束、长内容、键盘操作与手机验收。

Figma Auto Layout 仅作设计意图的近似映射，不与 CSS 值机械等同。Grid 留在第三节，不在第二节提前实现。第二节独立使用 `frontend-observatory.lesson2.v1` 存储进度，重置第二节不会清除第一节已有进度。

## 本地开发与静态构建

需要 Node.js 22.12+（或 Vite 支持的版本）。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`dist/` 是可部署到静态托管服务的产物，无后端和运行时密钥。Sites 的持久项目标识保存在 `.openai/hosting.json`，后续发布应复用该标识，不能重复注册。GitHub 代码公开与 Sites 访问权限独立；本站 Sites 使用仅本人访问的权限。

## 验证

```sh
# 使用当前环境的系统 Chromium
npm test

# 其他环境可指定浏览器可执行文件
CHROMIUM_PATH=/path/to/chromium npm test
```

Playwright 覆盖 1440×1050 桌面及 375×812 手机视口，回归第一节并验证第二节：双向点选、两种树的真实差别、消息实例上限与重复点击、共同样式、参数联动、纯文本安全显示、判断题重试、草稿编辑、复制成功/拒绝回退、浏览器进度恢复/重置、损坏或不可用的存储、键盘焦点、课程目录、页面横向溢出；第二节额外验证方向、gap、两轴对齐、grow/shrink 实测几何、长内容溢出与修复、课程间独立进度和重置、五站完整学习流程。两节所有步骤均运行 axe 的 WCAG A/AA 自动检查。

自动检查不能替代真实手机、辅助技术和多浏览器人工验收。学习时长为建议，不是计时限制。
