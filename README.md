## 第十五节：Loading / Skeleton / Optimistic UI

五站交互：同一本地手动延迟比较静态/可暂停 spinner、Skeleton 占位与已知示例进度；收藏对比等待确认和乐观预测，失败撤销预测后可重试；按条目与尝试编号处理乱序、重复、取消及重试。A 失败仅回滚 A，不恢复旧整表并删掉后来成功的 B。失败文字保留在恢复区，不假称已保存或服务器撤销。

所有结果均手动投递，无网络、真实服务器、文件读取或自动任务计时器；装饰动画默认暂停，尊重减少动态。状态反馈位于 aria-busy 内容外，不逐帧播报。当前操作将失效时安全接回焦点，外部已有焦点不被抢走。三道可重试判断题、可编辑复制简报与独立进度键 `frontend-observatory.lesson15.v1`，重置保留 01–14。会话条目与队列换站、离课、刷新或重置后清空；学习进度单独保存。使用普通 React State 展示原理，没有调用 useOptimistic 或请求库；后续开放状态以课程目录为准。官方资料核对日期 **2026-10-21**。

## 第十六节：State Machine

同一份普通 JavaScript 转换表驱动本地任务、可视状态图、原生事件按钮与完整文字事件表。6 个互斥业务阶段、8 种事件、11 条允许转换；未列出的组合一律阻止并解释。标题、确认与尝试编号守卫有真实失败路径，重复开始不会重复创建任务；失败可重试，取消使旧结果失效，新任务不会被旧成功或旧失败覆盖。重要标记与详情可并存，phase 始终单一。

图仅辅助，无拖拽、hover 或动画门槛；全部操作可触屏和键盘完成。没有接入 XState、Rive、网络或机器人；解释约束复杂度与状态数量的区别，以及视觉动画和业务流程的分层。结果按钮失效前有按当前焦点归属的安全恢复。判断题可重试，Agent 简报可编辑复制。独立进度键 `frontend-observatory.lesson16.v1`，保留 01–15；换站、离课、刷新或确认重置清空实验会话。官方概念核对日期 **2026-10-21**，Stately 当前文档包含 v6 alpha，不声称演示其 API；后续章节开放状态以统一课程目录为准。

## 第十七节：Micro Interaction

真实 hover、focus、press/tap 驱动两颗本地收藏按钮，对比 CSS transition 与手写 rAF 弹簧积分，明确未使用 Motion。调节位移、CSS 时长、弹簧配方和可编辑文案；解释刚度、阻尼、质量和插值/回弹边界，简单反馈先选 CSS，不给所有按钮强制弹跳。悬停不是门槛，触屏和键盘均有等价反馈与原生操作。

移出、pointercancel、失去捕获、Escape、keyup/blur 清理按压；长按不重复激活，禁用按钮无假成功。实时响应系统减少动态及手动暂停，停止非必要位移、保留文字/符号/aria-pressed与可见焦点；无逐帧播报、自动循环和联网。可重试题、编辑复制简报、独立进度键 `frontend-observatory.lesson17.v1`，重置保留01–16。官方资料核对 **2026-10-21**；25以后仍为预告。

## 第十八节：Enter / Exit Animation

对比直接条件卸载与真实通知列表的 entering / present / exiting / absent。原生 WAAPI 动画配合 React 手写存在管理，未使用 Motion；结束后真正从数据与 DOM 删除。进入和离场内容 inert，外部文字阶段表可读；移除持焦项前迁移到下个可操作项或添加入口，外部已有焦点不被抢走。

暂停、慢速与立即完成便于观察，不要求等待动画。快速反转保留同一节点及备注，旧实例/代次完成回调不得删除新状态；取消、重复请求、离课与卸载有清理。实时减少动态或能力失败即完成，不留下不可操作节点；已卸载后的撤回以新ID恢复内容，不伪称旧DOM复活。可重试题、编辑复制简报，独立进度键 `frontend-observatory.lesson18.v1`，保留01–17。官方资料核对 **2026-10-21**；25以后为预告。

## 第十九节：Spring

同一起点、同目标对比本地duration/easing时间插值与真实物理spring，可调刚度与阻尼、固定质量，体验迅速稳定和轻微回弹。运行中换目标时各自保留当前坐标，spring保留速度、时间插值重新计时；说明打断后起点可能不同，公平重试先归位。没有使用Motion或预制easing冒充spring，参数使用教学单位。

稳定1/240秒子步、单帧最多补算50ms、超过200ms帧间隔直接到位保护，误差/速度阈值与8秒安全终止。真实页面隐藏立即结算并取消rAF，返回不自动续播；实时减少动态呈现静态最新目标。重置/换站/离开清理失效回调，不逐帧播报，所有门槛有键盘与触屏路径。可重试题、编辑复制简报、独立进度键 `frontend-observatory.lesson19.v1`，保留01–18。官方资料核对 **2026-10-22**；25以后仍为预告。

## 第二十节：Layout Animation

真实卡片排序、移到最前、展开/收起与长内容改变正常布局；先提交DOM与高度，再用位置型FLIP和原生WAAPI平移。First来自当前视觉矩形，Last是新布局，快速反转重测当前画面，旧回调不能改回排序。同一ID与本地备注保留，无Motion依赖。

本例只动画位置，宽高和文字换行即时布局，插画固定比例，避免整卡scale失真，不教transition: all。持焦卡片尺寸改变时本卡直接最终位置、按需滚动以保留操作入口，邻卡仍可过渡；外部已有焦点不被抢。减少动态、容器宽度改变、隐藏或能力失败时取消过渡，真实布局仍生效；离课/卸载清理，无持续rAF。可重试题、编辑复制简报、独立进度键 `frontend-observatory.lesson20.v1`，保留01–19。与18进入退出、19物理spring和21共享元素区分，25以后仍为预告。官方资料核对 **2026-10-22**。

## 第二十一节：Shared Element Transition

快速请求以最新代次为准，skip仍执行更新的回调被守卫；来源缺失、能力不支持、创建失败、隐藏或实时减少动态直接提交最新视图。非模态详情不困住Tab，内部Escape与触屏返回等价，准确恢复来源或列表标题，外部焦点不被抢。备注按对象保留本次会话，换站/刷新/离课清空；可重试题、可编辑复制简报、独立键 `frontend-observatory.lesson21.v1`，重置保留01–20。官方资料核对 **2026-10-22**，25以后仍预告。

## 第二十二节：Scroll Animation

明确标注的局部滚动框，原生被动scroll事件按scrollTop/(scrollHeight-clientHeight)绑定进度与三阶段，20%–80%区间可选，反滚可回退。原生CSS scroll timeline细线实际绑定全程，IntersectionObserver另触发一次600ms只读反馈，区分入场触发与scrub；未安装GSAP。辅助按钮真实移动同一滚动框，不切假状态。

小读数带仅在框内CSS sticky，短视口或有效宽度很窄时解除，控件在框外；正常滚动、Tab退出和全文阅读不锁定。ResizeObserver重算内容/容器，0分母安全处理；减少动态实时停止位移/装饰动画，文字进度与完整正文保留。隐藏/换站/卸载清理单次待处理rAF、observer、监听和时间动画，无持续循环。可重试题、编辑复制简报、独立键 `frontend-observatory.lesson22.v1`，重置保留01–21。官方资料核对 **2026-10-22**，30以后预告。

离开/cancel/blur/隐藏/减少动态/重置清理，旧代次回调隔离；滚动/resize重算当前边界。触摸不跟随、不捕获、不劫持页面滚动，键盘/触屏分区按钮改变同样参数，减少动态保留静态聚光采样与完整内容。装饰pointer-events:none且无Tab目标，控件在变形区外。五站、解释重试、编辑复制brief，独立键 `frontend-observatory.lesson23.v1`，重置保留01–22。官方资料核对 **2026-10-22**，30以后预告。
