## 第十五节：Loading / Skeleton / Optimistic UI

## 第十六节：State Machine

同一份普通 JavaScript 转换表驱动本地任务、可视状态图、原生事件按钮与完整文字事件表。6 个互斥业务阶段、8 种事件、11 条允许转换；未列出的组合一律阻止并解释。标题、确认与尝试编号守卫有真实失败路径，重复开始不会重复创建任务；失败可重试，取消使旧结果失效，新任务不会被旧成功或旧失败覆盖。重要标记与详情可并存，phase 始终单一。
